# 辅助武将：老君 / 文殊 + 唐僧受伤免疫

日期：2026-08-11  
状态：已定稿  
范围：`web/src/generals.ts`、`battle.ts`、`weapons.ts`、`render.ts`、`docs/hero-combat-reference.md`

## 背景

当前 10 门派中仅「音」线（观音/梵音）为辅助向，且观音实质是「减速 + 每波唐僧 +1 血」的控辅混血。辅助生态偏薄，且唐僧仅 3 点血时，同帧多怪撞线会连扣致死、缺少反应窗口。

## 目标

1. 新增两个辅助门派：**君**（老君）、**殊**（文殊），各含满 5 + 满 3 过渡，机制与观音明确分工。
2. 唐僧漏怪扣血后短暂免疫，避免扎堆同帧多扣。
3. 大招有可辨识动画与文档口径，数值进 `TUNING`。

## 与观音的分工

| 武将 | 作用对象 | 核心价值 | 不做什么 |
|------|----------|----------|----------|
| 观音 | 怪 + 唐僧 | 范围减速 + 每波限一次续命 | 不增益友军武将 |
| 老君 | 友军武将 | 短时全体攻击加成 | 不回唐僧血、不控怪 |
| 文殊 | 友军武将 | 缩短其他武将大招剩余 CD | 不回唐僧血、不控怪、自身几乎无爆发伤 |

## 大招设计

### 射程与 CD（全武将口径，辅助例外）

- 选中武将时的黄色范围环 / 面板「范围」= 普攻与**对怪大招**共用的 `rge`（+`rangeTolerance`）。
- 对怪大招：CD 就绪 **且** 圈内有怪才放；无怪时 CD 停在 0 憋招。
- `buff`/`cdr`：仅要求 CD 就绪即可放；普攻仍吃同一射程环。
- 面板「大招CD」展示 `skillCd`；激活后显示剩余 / 总额。

### 老君 · 炼丹·金丹（`buff`）

- **触发**：大招 CD 就绪即可施放（**不要求**射程内有怪）。
- **效果**：为场上全部已激活友军武将（含自己）施加短时攻击倍率。
- **数值**（`TUNING`）：
  - 满 5：`heroBuffAtkMulMain = 1.35`，`heroBuffDurMain = 5` 秒
  - 满 3：`heroBuffAtkMulTransit = 1.20`，`heroBuffDurTransit = 3.5` 秒
- **叠乘**：与仙丹 `pillAtk`、羁绊、神兵 atk% **乘算**；同效果刷新时长取 `max`（不叠层）。
- **DPS 账本**：`heroSkillFocusDps` 计 0（与 heal 同口径：不直接打怪）。
- **动画意象**（约 0.85s）：八卦炉升起 → 太极/八卦环转 → 金丹环绕外溅 + 地火冲击与火星（暖金，区别观音冷青）。

### 文殊 · 般若·慧剑（`cdr`）

- **触发**：CD 就绪即可施放（不要求怪在射程内）。
- **效果**：缩短**其他**已激活武将的大招剩余 CD（不改自己的刚重置 CD）。
- **数值**：
  - 满 5：`heroCdrSecMain = 4` 秒
  - 满 3：`heroCdrSecTransit = 2.5` 秒
  - 结算：`skillCd = max(0, skillCd - cdrSec)`
- **边界**：仅一人上场时施放无友军效果，仍重置自身 CD（浪费一拍，可接受）。
- **DPS 账本**：计 0。
- **动画意象**（约 0.85s）：双层青莲反向展开 → 三道慧剑弧斩 → 光尘/花瓣外散（青金/莲紫，区别老君暖金）。

## 唐僧受伤免疫

- 漏怪扣血成功后：`tangsengHurtImmuneT = TUNING.tangsengHurtImmuneDur`（**0.5** 秒）。
- 免疫期内再有怪越线：**移除该怪，不扣血、不给舍身饲魔蟠桃**（避免免疫窗刷桃）。
- AI 侧唐僧同步同一规则（`aiTangsengHurtImmuneT`），对称伪竞技。
- 每帧衰减免疫计时。

## 非目标

- 不改观音每波 +1 血公式（本迭代只补差异化辅助）。
- 不为 AI 武将补全套大招施放（现状 AI 武将本就不放大招）。
- 不新增唐僧百分比 HoT / 护盾技能（留给后续）。

## 验收

1. `GENERALS` 24 人、12 门派；每门派一满 5 一满 3；神兵一一对应。
2. 老君大招后友军 `generalAtk` 在持续期内按倍率提升；结束后恢复；无怪亦可放。
3. 文殊大招后其他武将 `skillCd` 减少对应秒数，自身刚重置的 CD 不被缩短；无怪亦可放。
4. 连续两只怪同帧越线：只扣 1 血，第二只被免疫吞掉。
5. `docs/hero-combat-reference.md` 与 `TUNING` 常量名/数字一致。
6. 武将面板展示「大招CD」；帮助文案覆盖观音/老君/文殊与 CD/射程口径。
7. 自动化：`web/tests/support-heroes.test.ts` + `general-family` / `hero-ult` / `menu-help`。
