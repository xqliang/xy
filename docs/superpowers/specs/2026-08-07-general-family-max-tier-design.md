# 武将门派 · 满级差 · 继承 · 征兵配对

日期：2026-08-07  
状态：已定稿  
范围：`web` 武将配置、字牌合成/激活/升阶、征兵抽字、武将信息面板

## 背景

竞品武将有不同满级（核心满 5 / 过渡满 3），且同门派武将共享一字以便继承练级。当前实现：

- 12 武将统一 `MAX_TIER=5`，无门派/满级差
- 单字同阶可合并升阶（与竞品不符）
- 字牌死绑 `general` id，无法「一字多用」
- 征兵仅有「出字保底」，无配对补缺、无前期满 3 / 后期满 5 权重

### 2. 数据模型

`GeneralDef` 新增：

- `maxTier: 3 | 5` — 品质阶上限
- `atkStyle: string` — 攻击方式文案（如 `快攻贯穿`）
- `family: string` — 门派共享字（如 `悟`）

字牌 `PlacedWord` / tray word token：

- 保留 `char` + `tier`
- `general` 改为可选或在落子时可不唯一；**激活时按左右字匹配** `GENERALS` 中 `chars` 序对决定武将
- 推荐：字牌存 `char` + `tier`；若需兼容，`general` 可在抽到时标「候选家族」但不阻止另配

匹配规则：左格字 = `def.chars[0]` 且右格字 = `def.chars[1]`（须左右紧邻）→ 激活该 `def`。

### 3. 品质阶上限

- 满 5：最高橙（5）；满 3：最高紫（3）
- 所有升阶路径受 `def.maxTier` 约束：激活继承、喂字、战斗经验升阶、法宝符首次 +1
- 信息面板标注：`{atkStyle}·满级{maxTier}`

### 4. 激活继承对齐

激活瞬间（**只升不降**，避免共享字在满 3 武将上被削阶）：

```
cap = def.maxTier
target = min(max(left.tier, right.tier), cap)
if left.tier < target: left.tier = target
if right.tier < target: right.tier = target
```

拆开后各字保留当前阶。激活展示/战力阶 = `min(left.tier, right.tier, cap)`。

无法匹配任何武将：不激活、不对齐。

### 5. 禁止单字合并

- 两张同字同阶**不可**合成升阶（tray 内、棋盘落子、棋盘拖拽均禁止）
- 拖到同字同阶：交换位置或提示「单字不可合并」，不消耗
- 合法升阶：激活继承、喂已激活武将、战斗经验、法宝符

### 6. 征兵字牌

**阶段权重（按波次 `battle.wave`）**

| 波段 | 满 3 相对权重 | 满 5 相对权重 |
|------|--------------|--------------|
| 1–4 | 高（0.8） | 低（0.2） |
| 5–7 | 中（0.5） | 中（0.5） |
| 8+ | 低（0.2） | 高（0.8） |

（系数需压过满 3 基础 `weight≈3`、满 5 `weight≈1` 的差距，保证后期满 5 总权重更高。）

在基础 `weight` 之上再乘阶段系数；招贤榜只乘出字率。

**配对优化**

1. **孤儿补缺**：棋盘或本盘 tray 有某字、且该字尚能参与未激活武将时，下一张字对「可与之成对的字」加权
2. **半对保底**：连续 **4** 次征兵仍存在未补孤儿 → 强制下一张字牌为可完成某孤儿配对的字
3. **同盘协同**：同盘已出一张字时，其余字槽对能与之成对的字加权（不强制整盘出对）

**保留**：连续无字保底（`wordPityAfter: 10`）；首次征兵不出字。

**不做**：直接往棋盘塞字；一次征兵必出完整一对。

### 7. UI

- `drawWordSelection`：标题行含攻击方式与满级，如 `二郎 · 远程暴击 · 满级5`
- 棋盘名号可保持短名；详情以面板为准
- 满 3 武将字牌阶徽标不超过 3

## 非目标

- 不改兵种合成、`MAX_TIER` 全局常量（兵种仍 5；武将用 per-def `maxTier`）
- 不恢复战斗 Lv 加攻 UI
- 不新增唐僧武将 / 双人羁绊
- 不重做大招动画资产（新武将可先复用同 `skill` 族动画或占位）

## 验收清单

1. 满 3 武将品质阶无法超过 3；满 5 可到 5；面板有满级标注与攻击方式
2. 同门派共享字可分别与两个右/左字组成对应武将
3. 高阶字 + 低阶字激活 → 低阶对齐到高阶（受 maxTier）；拆开保留
4. 两张同字不能合并
5. 前期（1–4 波）满 3 字明显更多；后期（8+）满 5 更多
6. 有孤儿时后续抽字倾向补缺；连续 4 次未补则强制补缺字
7. 悟空上场羁绊仍生效；弥勒/御弟不再出字
