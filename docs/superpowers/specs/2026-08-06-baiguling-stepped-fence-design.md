# 白骨岭（巨鹿）台阶篱笆地图设计

## 背景
白骨岭对应竞品「巨鹿」。当前实现与其它三图一样：水平 `FENCE_ROW=5` 切上下各 5 行、木栅栏、路径与唐僧偏左下。竞品则是**路径即分界**的台阶形半场，唐僧在对角，栅栏为白骨堆且**无开口**。

## 目标
重做白骨岭半场/路径/初始槽/栅栏视觉，贴近竞品布局；其余三图行为不变。

## 坐标约定
文档与口头「第 R 行第 C 列」按竞品截图 **1 起算**；代码 **0 起算**（行/列均 −1）。棋盘仍为 `COLS=8`、`ROWS=10`。

## 路径与唐僧
白骨栅栏画在台阶分界格线上（左 `r=5|6`、竖 `c=3|4`、右 `r=3|4`）。  
玩家路径贴着栅栏**我方外侧**走（不穿栅栏）：

```
(-1,9), (0,9), (0,8), (0,7), (0,6),     // 左下角出怪，沿左缘上行
(1,6), (2,6), (3,6),                   // 贴左段栅栏（我方侧 r=6）
(4,6), (4,5), (4,4),                   // 拐角外侧，贴竖段（我方侧 c=4）
(5,4), (6,4), (7,4),                   // 贴右段栅栏（我方侧 r=4）
(7,5), (7,6), (7,7), (7,8), (7,9)      // 右缘下行至唐僧
```

路径与**可挖格**（含未解锁）的交界边用黑色加粗线区分（路径彼此之间不画；不用白骨描边）。

- `tangseng: { c: 7, r: 9 }`；AI 镜像 → **右上角出怪** `(7,0)`，AI 唐僧 `(0,0)`

## 半场判定（替代死板 `r >= 5`，仅白骨岭）
非路径格归属：

| 列 (0-index) | 分界路径行 | 我方 | AI |
|---|---|---|---|
| `0..3` | `r=5` | `r >= 6` | `r <= 4` |
| `4..7` | `r=3` | `r >= 4` | `r <= 2` |

路径格不可放置。其它三图继续 `r >= FENCE_ROW`。

实现建议：`board.ts` 提供 `isPlayerCell(map, c, r)`；`placeableCells` / `battle.isPlaceable` / `render` 半场分支统一走它。默认实现：`r >= FENCE_ROW`；白骨岭用上表（或等价的 per-map `sideOf`）。

180° 对称：非路径格满足「我方格的镜像为 AI 格」。

## 初始槽位
下方红框 6 格写入 `initialBlock`（1 起算：列 3–5、行 8–9）：

```
(2,7), (3,7), (4,7), (2,8), (3,8), (4,8)
```

上方由镜像自动生成（约列 4–6、行 2–3 一带；与竞品上方 4×2 不完全同形，受对称约束可接受）。

`fenceGaps: []`（本图无开口；字段保留以兼容其它图）。

## 栅栏：Q 版白骨堆（无开口）
- **必须有栅栏**：上下半场之间沿台阶分界连续铺满，**不存在开口**（出怪口不靠挖栅栏缺口）。
- **素材**：Seedream（火山方舟 Ark，现有 `web/tools/seeddream/` 管线）生成 Q 版白骨堆图标 → 抠透明 PNG。
  - 建议 key：`fence-baiguling`
  - 风格：与现有单位一致——扁平、粗黑描边、小白骨/骷髅堆，可作栅栏段重复贴图；白底便于抠图
- **绘制**：白骨岭沿分界（左段贴 `r=5` 路径边、竖拐角、右段贴 `r=3` 路径边）按格或按段重复绘制精灵；**整段无 gap**。其它三图仍用水平木栅栏 + 各自 `fenceGaps`。
- **缺图兜底**：简白骨矢量/色块占位，不阻断游玩。
