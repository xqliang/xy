# 对战无限波 + BOSS 段预排程

**日期：** 2026-08-08  
**状态：** 已批准（对话确认）  
**范围：** 对战模式胜负/波封顶；无尽与对战共用的妖王波预排；小 Boss 与妖王互斥

## 问题

1. 对战在清完第 12 波即通关，与「和 AI 比谁先死」的伪竞技目标不符。  
2. 无尽「每 5 波固定妖王」节奏过死；需要对战与无尽统一为分段预随机。  
3. 小 Boss 不得与大 Boss 同波（第 5 波起才出现）。

## 目标

### 对战（`endless === false`）

- 取消「`wave >= winWave` 清波即胜」  
- 波数不封顶；清波后继续下一波  
- 胜负仅：对方唐僧先死 → 胜；己方唐僧先死 → 负  
- 怪物难度与无尽相同：每 10 波 × `endlessCycleStep`（1.3）  
- 结算仍按胜负涨降境界 + 功德（波数参与功德）

### 妖王波预排（无尽 + 对战共用）

| 区间 | 规则 |
|------|------|
| 1–4 | 无妖王 |
| 5–10 | 预随机 **1–2** 个妖王波 |
| 11–20、21–30… | 每段 10 波预随机 **2–3** 个妖王波 |

- 开局生成首段；进入下一段前（或按需懒生成）用**独立 BOSS RNG** 算好本段：出几个、哪几波  
- 段内波次互不重复，数量落在闭区间  
- **删除** `bossEveryWave` / `wave % 5 === 0` 及依赖 `winWave` 的旧 `computeBossWaves`

### 小 Boss

- 仅第 5 波及以后（保持 `miniBossFromWave = 5`）  
- **不与妖王同波**（`isBossWave` 为真时不 roll 小 Boss）  
- 概率等其余逻辑可保持现状

## 非目标

- 不改无尽「关 AI、只记最高波」  
- 不改小 Boss 光环技能数值  
- 不强制改 UI 文案（HUD 波次数字可继续涨）

## 实现要点

1. **`effectiveDifficulty`**：对战与无尽都走分圈阶梯（去掉「仅 endless 才加压」的守卫，或改为「非无尽也对战加压」——对战/无尽均加压）。  
2. **`BossSchedule`（或 Battle 私有表）**：`Set`/`Map` 存已排妖王波；`ensureBossSchedule(wave)` 覆盖含该波的段。  
3. **段定义**：  
   - 段 0 特殊：候选波 `{5,6,7,8,9,10}`，数量 `1 + rng.int(2)` → 1..2  
   - 段 `k≥1`：波 `10k+1 .. 10k+10`，数量 `2 + rng.int(2)` → 2..3  
4. **`isBossWave(w)`**：查预排表（先 `ensure`）。  
5. **清波通关**：删除 `!endless && wave >= winWave → won`；`winWave` 可废弃或仅留注释/测试清理。  
6. **测试**：段内数量约束、1–4 无妖王、小 Boss 不与妖王同波、对战清波 12 不胜、对战有效难度随圈上升。

## 验收

- 对战打过第 12 波仍继续，直至一方唐僧阵亡  
- 无尽/对战均无「每 5 波必出妖王」  
- 5–10 恰有 1–2 个妖王波；之后每 10 波恰有 2–3 个  
- 妖王波无小 Boss
