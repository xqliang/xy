# 武将字号统一 · 攻击升阶 · 字牌征兵保底

日期：2026-08-06  
状态：已定稿（待实现）  
范围：`web` 候选区字牌绘制、激活武将局内成长、征兵字牌保底

## 背景

1. **字号不一致**：候选区（tray）武将字牌单字比地图格上的字视觉更大，需统一。
2. **攻击升阶预期不符**：玩家期望激活武将随攻击提升**品质阶**（右上角徽标），拆开后字牌保留新阶。现有「战斗 Lv + 经验条 + 每级 +8% 攻」与徽标无关，且界面已去掉 Lv 显示，容易误以为不会升级。
3. **字牌过稀**：字牌只在非首次征兵时按概率从兵槽转换，无保底；连续多次征兵可能一张字都没有。

## 目标行为

### 1. Tray 字号与地图一致

- 地图字牌：`drawWordTile(..., CELL * 0.78)`。
- 候选区字牌：改为同一 `s = CELL * 0.78`（缩小 tray 侧，对齐地图）。
- 候选区兵种 / 铲子令牌尺寸**不变**（仍用现有 `TRAY_H - 16` 等）。

### 2. 攻击升品质阶（去掉战斗 Lv）

**升阶规则**

- 仅对**已激活**武将（左右紧邻、顺序正确的双字）生效。
- 攻击与技能仍可按现有输出/固定量累加内部经验条；经验满一次 → **左右字牌各 `tier + 1`**。
- 单字已达 `MAX_TIER`（5）则该字不再涨；另一字未满仍可涨。
- 激活徽标阶 = `min(左.tier, 右.tier)`，因此例如「二 2 + 郎 3」显示 2；升阶后「二 3 + 郎 4」显示 3。
- 拆开 / 拖走一字后，字牌保留各自当前阶（无额外结算）。

**删除 / 停用**

- 战斗等级对攻击力的加成（`generalAtk` 中 `1 + 0.08 * (level - 1)`）。
- 地图金框下方经验条、选中面板「等级 Lv.n」。
- `GeneralState.level` / `exp` 若仅服务于上述成长，改为仅作「升阶进度」内部计数（或等价字段），**不再对玩家展示为 Lv**。

**攻力来源**

- 激活武将攻击力只由品质阶（`generalStat`）、武器、mods、羁绊等现有非 Lv 因子决定。

**法宝符（`fabaofu`）**

- 效果改为：武将**首次激活**时，两字各 +1 阶（受 `MAX_TIER` 限制）。
- 文案改为「武将初始品质阶 +1」（或等价表述）。
- 去掉对已删除「初始战斗等级」的依赖（`generalLevelDelta` 可改为 `generalTierDelta` 或复用并改语义）。

**节奏**

- 首次实现沿用当前经验阈值与 `dmg * hit * 0.05` / 技能 +4 等系数；过慢或过快再调，不在本规格锁定具体击杀数。

### 3. 字牌征兵保底（对齐铲子保底模式）

- 新增 `wordPityAfter: 10` 与计数 `summonsSinceWord`（命名可等价）。
- 每次成功征兵后：
  - 若本盘 tray 中 **至少 1 张字牌** → `summonsSinceWord = 0`；
  - 否则 → `summonsSinceWord += 1`。
- 当 `summonsSinceWord >= wordPityAfter` 且**非首次征兵**时：本盘**强制至少 1 张字牌**。
- **强制方式**：在兵/铲分布与概率转字完成之后，若仍无字牌，则把 **1 个普通兵槽** 换成字牌。
- **不得修改其他保底牌**：
  - 不替换铲子（含铲子保底 `forceShovel` 强制出的那张）；
  - 不改写已因铲子保底 / 首次征兵约束固定下来的非目标槽语义；
  - 只动一个「普通 unit」槽。
- 首次征兵仍不转字、不触发字牌保底（维持 ≥4 兵等现有约束）。
- `招贤榜` 的 `wordRateBonus` 仍作用于概率转字；与保底独立（保底是下限）。

## 非目标

- 不改品质阶合并 / 喂字升阶规则（同字同阶合并、等阶喂激活武将等保持现状）。
- 不改为「每 10 波」掉字或直接往棋盘丢字。
- 不恢复地图上的 `Lv.n` 名号样式。
- 不调整 `MAX_TIER`、征兵成本曲线、铲子保底次数（仍为 3）。

## 实现要点

### 绘制（`web/src/render.ts`）

- `drawTray` / `drawTrayToken`：`token.kind === 'word'` 时使用 `CELL * 0.78`。
- `drawGenerals`：移除经验条绘制；名号保持现有小字全名即可。
- `drawWordSelection`：去掉「等级 Lv.n」行（若存在）。

### 战斗（`web/src/battle.ts`）

- `gainGeneralExp`（或重命名）：满条时对激活武将两字 `tier++`（封顶），并打升阶 burst / 提示；不再 `level++` 加攻。
- `generalAtk`：去掉 level 系数。
- `summon`：维护 `summonsSinceWord`；保底替换时 `findIndex` 第一个 `kind === 'unit'` 再换成 `WORD_POOL` 抽取结果。
- `TUNING.wordPityAfter = 10`。
- 被动注入：法宝符改阶数语义；更新相关测试。

### 测试

- 字牌保底：连续 10 次无字后第 11 次（或达到阈值的当次）必有 ≥1 字；且强制替换不把 shovel 槽改成字。
- 升阶：二 2 + 郎 3 激活后模拟满经验 → 二 3、郎 4，`active.tier === 3`；拆开后字牌阶保留。
- 满阶边界：一字已 5 时只升另一字。
- 回归：首次征兵无字、铲子保底仍生效。
