# 道具商城（收编进被动技能商店）实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 移除仍死在 `battle.ts` 的旧局内道具获取链，把值得保留的 `ITEMS` 收编进现有「每日被动技能商店」框架；购买改为「不限次数、最新 2 主动 + 6 被动生效、后买挤旧」。

**Architecture:** 商城元数据统一到 `passives.ts`（`PASSIVE_SKILLS`），效果实现复用 `battle.ts` 现成的 `applyItem`/`updateItemEffects`/`mods`，购买走 `loadout.buyPassive/buyActive`（改 FIFO 挤旧），开局经构造函数 `passives` 参数按 id 通用注入。

**Tech Stack:** TypeScript + Vite + Canvas 2D；测试 vitest（node 环境，无 `localStorage` → 测 loadout 需注入内存版）。

**参考规范：** `docs/superpowers/specs/2026-08-05-item-shop-design.md`

**所有命令的工作目录为 `web/`**（vite 工程根）。
